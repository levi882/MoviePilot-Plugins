# FEL 自动重建 0.3.2（实验性）

沿用 MoviePilot 原有电影目录和播放器入口。刮削完成、影片与 NFO 稳定后，读取视频码流识别双层 Dolby Vision；符合条件的 P7 FEL 由独立处理服务重建为 P8.1。

**这是实验版：已完成短片流程与播放验证，整片及长时音画同步尚未验收。FEL 重建后经过 10-bit 有损重编码，不是无损转换，也不是盒子原生双层解码。**

## 安装

MoviePilot V3（>=3.1.8，<4）中将以下 GitHub 仓库加入第三方插件市场，在插件市场安装“FEL 自动重建”：

```text
https://github.com/levi882/MoviePilot-Plugins
```

插件还需[独立处理服务](../../services/felplayback/README.md)。只安装插件不会自动部署编码引擎；未配置处理服务的目录会提示原因，不会改用其他目录。

## 使用

照常在 MP 下载、整理、刮削和播放。插件自动读取 MP 的电影目录规则，无需另建播放库。成品写入对应下载目录的 `.FEL-Rebuilt/<任务ID>/`，通过校验后硬链接到原电影库的同名位置，并重新刮削。做种文件保持不变，替换前的库内原文件通过任务目录中的 `original.keep` 保留。

配置页的“启用插件”“仅检测”“暂停处理”和等待秒数是常用设置；目录详情、手动处理、清理维护默认折叠。显示的目录来自安装者本机 MP 设置，不内置作者的 NAS 路径。默认禁用、仅检测；首次使用建议保持暂停，确认服务挂载与存储正常后先测试短片。

下载目录与电影库必须位于支持硬链接的同一文件系统，路径不能经过符号链接。多个下载目录歧义、源片变化、成品冲突或校验失败时停止发布，保留原文件。插件启用时将 `.FEL-Rebuilt` 加入 MP 整理排除规则，防止成品重复整理；保留其他排除项。

## 支持范围

- 单主视频轨的 HEVC P7 FEL MKV；BL 3840×2160、EL 1920×1080。
- 恒定帧率、视频从零起始、BL/EL/RPU 帧数一致，可解析的母版元数据。
- 复制原音轨、字幕、附件和章节；检查时间轴、载荷摘要及 RPU 回读。
- P5、P8、HDR10 和普通影片不进入 FEL 重建。MEL、ISO/BDMV、其他 P7 封装及不支持的时间轴不会自动转换。
- 首次启用不自动重转历史库，可在“手动处理”加入单个文件。

## 清理与恢复

先暂停并等待当前任务结束，在“清理与维护”选择清理历史、归档日志，开启“保存后清理一次”并保存。仅处理已结束且超过60秒的任务，失败、未完成、待重试及等待入库任务保留。

历史通过归档标记隐藏，处理日志压缩存放于插件队列的 `archive/logs/`。开启“保存后恢复历史与日志”可恢复，不重新排队、不覆盖新日志。任务状态、发布回执、校验报告、原片、成品和原片备份保留，避免重复重建。不会清空 MP/系统全局日志，也不会永久销毁归档。

## 隐私与开源

插件不上传影片或目录配置。处理服务运行时断网，原片挂载只读；MP 自身刮削按其现有设置联网。运行配置、目录映射、任务和处理日志只存放在安装者本地。共享问题报告时应自行去除路径、影片名和凭据。

此发布只包含通用源码、合成测试、部署示例与第三方来源说明，不包含开发环境配置、截图、影片、队列或日志。代码按仓库 GPL-3.0 许可证提供；第三方代码保留其许可证与署名，见 [NOTICE](../../services/felplayback/NOTICE.md)。
