# FEL 发布内容与隐私边界

本次发布使用显式文件允许名单，只包含插件、处理服务源码、第三方源码及许可证、合成测试、通用部署示例与文档。运行数据没有通过递归复制进入发布目录。

以下内容不进入仓库：本机目录映射与运行配置、局域网地址、账号凭据、站点设置、队列与任务记录、处理日志、影片、恢复备份、测试截图和个人部署说明。示例目录与UID/GID必须由安装者自行填写，不携带开发环境的真实值。

静态检查覆盖私网 IPv4、个人挂载路径、常见凭据赋值和私钥头；另人工核对新文件清单及第三方来源。静态扫描有局限，问题报告仍需人工脱敏。本文仅描述本插件新增内容，不对仓库已有插件作隐私承诺。

插件配置页显示的路径由安装者本机 MoviePilot 在运行时提供，不会写回 GitHub 源码。目录默认折叠只用于界面简洁，不是访问控制；请妥善保护 MP 账号与本地数据。

处理服务运行时断网、源片只读。MP 的刮削仍按现有 MP 设置联网；本插件不增加影片、目录或日志上传功能。
